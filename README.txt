Ameloua Cloud Admin V2 – Testversion
Nur für das separate Repository Ameloua-Stempeluhr-Test.
Neue Funktion: Korrektur von Beginn/Ende und Grund für bestehende Arbeitszeiten, nach Admin-Anmeldung und ausdrücklicher Bestätigung.
WICHTIG: Korrekturen verändern die Daten in Supabase tatsächlich. Die alte lokale Stempeluhr wird nicht synchronisiert. Bestehende Pausen werden nicht angepasst. Keine Stempelbuchungen möglich. Bitte nur mit einer bewusst ausgewählten Testbuchung ausprobieren und zuvor ein Datenbankbackup sichern.
Dateien: index.html, cloud.js, styles.css, README.txt. Die alte app.js kann im Testrepo verbleiben, wird nicht verwendet.
